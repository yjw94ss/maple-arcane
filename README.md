# 枫之魔法师 · Maple Arcane

冒险岛风格的 2D 横版法师动作游戏。纯原生 JS + Canvas2D，无框架、无构建、无图片资源（所有美术都是代码画的）。

## 玩法

**桌面**：`A` / `D` 移动 · `空格` 跳跃 · `1`–`9` 释放技能 · `ESC` 暂停 · `H` 技能说明

**手机**：左侧 `◀ ▶` 移动 · 右侧 `⤒` 跳跃 · 底部点技能（**按住可连发**）。建议横屏。

手机端的技能排列不是按键盘 1-9，而是按右手拇指够得到的距离排的——最常用的「魔法弹」贴在最右，长冷却的「陨石术 / 圣光治愈」放最左。支持多点触控，可以边跑边打。

## 核心机制

9 个技能分属火焰 / 冰霜 / 雷霆 / 奥术 / 神圣五种元素。先给敌人挂状态、再用对立元素命中会触发元素反应：

| 组合 | 反应 | 效果 |
|---|---|---|
| 灼烧 + 冰霜 | 蒸汽爆裂 | 2.0× 范围伤害 |
| 冰冻 + 雷霆 | 霜雷爆 | 2.5× 碎裂爆发 |
| 感电 + 火焰 | 燎原 | 1.9× 连锁扩散 |

1.6 秒内连续命中不同元素会累积「元素连携」倍率（最高 x1.9），所以正确打法是 `2 → 3 → 4` 循环而不是无脑按一个键。

## 内容

- 6400px × 3 区域世界（枫叶草原 / 幽雾洞窟 / 星陨神殿），28 个平台、24 个刷怪点、5 种怪物
- Boss 暗影魔君：8200 HP，弹幕 / 震地 / 召唤三套行动，42% 血量进狂暴
- 升级、掉落、暂停/帮助/死亡/通关完整流程
- 程序化 WebAudio 音效

## 运行

双击 `index.html` 即可，无需服务器（`file://` 直接跑）。

调试参数：`?touch=1` 强制触摸控制，`?touch=0` 强制键鼠。
